# رحّالة | Rahala

An Arabic-first Android geography adventure covering the world, designed for short, enjoyable learning sessions and offline play.

## Development
- Flutter / Dart, Android-first, native RTL.
- Read [GAME_DESIGN.md](GAME_DESIGN.md) and [AGENTS.md](AGENTS.md) before implementation.
- Cloud-only workflow: Codex + GitHub Actions. No local SDK required for the owner.
- First milestone: a tested, installable debug APK with a polished playable vertical slice.

## Status
Project initialization; no playable build yet.
